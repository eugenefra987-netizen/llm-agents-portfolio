# LLM-агенты для реального бизнеса

**Евгений Бучацкий** · архитектор и разработчик LLM-агентов

Проектирую системы ИИ-агентов, которые работают каждый день, а не только на демо.
Код рабочих систем закрыт — здесь устройство, решения и результаты.

## Принципы
- **Модель предлагает — код проверяет — человек подтверждает.** У модели нет права самой записывать данные
  или совершать значимое действие: детерминированный контроллер проверяет результат и сохраняет,
  ключевые шаги (публикация, сделка) — за человеком.
- **Персональные данные не уходят за рубеж.** Российский контур обезличивает данные на входе; зарубежные
  модели работают только с обезличенными. Модель подключается через маршрутизатор — YandexGPT, GigaChat,
  DeepSeek, OpenAI, Claude — без правки кода.
- **Обучаемость, а не самообучение.** Поведение агента правят рекомендации владельца, а не переписывание кода.
- **Журнал всего.** Записи только добавляются; журналы решений и инцидентов — по каждому проекту.
- **Агенты печатаются из общего каркаса.** Охрана действий, сохранение через контроллер, память обратной связи,
  команды и связь с человеком — одинаковые у всех агентов; своё у каждого — только роль и проверки.
- **Внешние тексты — данные, а не инструкции** (защита от prompt injection). «Нет данных» ≠ «хорошо».

## Проекты

### 1. «Гид по миру» — система автоматизации турагента → [архитектура](SYSTEM.md)
Модульная система агентов: контент для турагента + подбор туров. 13 модулей, 6 уже работают,
контент-менеджер — в тестовой эксплуатации (первый агент, собранный на общем каркасе).
Каждый модуль автономен и с самого начала задуман частью целого — новые агенты подключаются без переделки системы.
У каждого агента своя память; задания между ними разносит рабочий стол по маршрутам, путь каждого задания записывается.

**Живой результат:** Telegram-канал [«Гид по Миру 🌍»](https://t.me/your_guide_to_the_world) — тексты пишет агент-автор.
- Автор работает автономно: сам запускается утром, читает новости, предлагает темы, проверяет факты, пишет.
  Тексты принимаются почти без правок; правки — только там, где рекомендации владельца неточны.
- Редакционная память: план (квартал → месяц → неделя), рекомендации по стилю с условиями применения,
  архив опубликованных текстов с метками тем — агент не повторяется. 100+ публикаций, 70+ задокументированных исправлений.
- Агент сам остановил ошибочную отраслевую новость: перед написанием проверил источники и выяснил, что новость неверна.
- Связь с агентом — и из Telegram: сообщение (в том числе голосовое) продолжает его рабочую сессию.

**Контент-менеджер (тест с 31.10.2026).** Собран на общем каркасе: утренняя сводка, контент-план, слежение за событиями,
новостями и конкурентами. В первый же день предложил тему по календарю событий (День мёртвых в Мехико, даты проверены
по официальному сайту), которую пропустил автор. Отсюда следующий шаг: календари сезонности и событий подаёт модели
сама система — сигналами в каждом задании, а контроллер проверяет, что ни один сигнал не пропущен.

### 2. Аналитик отелей — часть системы «Гид по миру»
Знать про отель то, что знает опытный турагент, прочитавший все отзывы.
- **Сборщик** собирает карточки и отзывы с десятка сайтов. Каждая найденная страница сверяется с «паспортом» отеля
  от туроператора (точка на карте, адрес, телефон, название, звёзды): засчитывается только «тот самый» отель.
- **Модель-разметчик** размечает каждый отзыв: пункт, плюс/минус, тяжесть 1–4, цитата.
- **Собственный рейтинг** по формуле с учётом свежести: «долгоживущие» пункты (номер, пляж) и «меняющиеся» (питание, сервис) считаются по-разному.
- **Аналитик (LLM)** дважды в день разбирает журнал сборщика и находит его повторяющиеся ошибки; по его разборам
  правила сверки уточняются, и каждое правило перед включением проверяется на всех его прошлых вердиктах.
  Независимые проверки вторым агентом (выборки по 30 карточек): чужих страниц среди засчитанных — 0 из 118 в первой,
  3 из 127 во второй (отели одной сети); причина закрыта отдельным правилом.

630+ отелей в базе, в очереди ~1300 (Турция, Египет, ОАЭ, Таиланд, Вьетнам, Мальдивы, Греция).

### 3. Исследовательский торговый агент (Мосбиржа) → [результаты](livermore.md)
Авторская торговая система переведена в строгие правила и проверена на 7 годах истории.
Решения о сделках принимает код, ИИ — аналитик. Лучший портфель: 100 000 ₽ → 343 000 ₽ за 2019–2026
при худшей просадке −17% (индекс за тот же срок — 89 000 ₽). Исследование, реальной торговли нет.
